## Context

Retained maintenance assessments found that running source and state paths could differ from setup defaults or appear under different path aliases. Backend closure alone also leaves separate direct-ComfyUI and Bot endpoints outside that boundary. A process snapshot or an empty aggregate queue does not establish every effective binding or global quiescence.

## Why

A checkpoint of the default directory or a hold on only one transport can miss the state or caller that matters.

## How to apply

Within the exact task grant, bind affected consumers and persistent paths to dated observations and explicit visibility limits. Resolve aliases using realpath, entry-point shebang and selected install/path metadata; keep actual import-origin evidence distinct. Enumerate literal symlinks and external targets without silently following them or double-counting targets covered by another protected root. Name actual controls, actors and endpoint coverage; a no-call promise is a caller hold, not a disconnected transport. Keep real manual acknowledgements separate from proxy approval.

Admit an authorized preflight task using its fixed grant, inputs, control arrangements and stop rules; do not demand that future task's own receipts before it exists. Require actual caller/intake and compute-safety holds before service stops, and cold closure/checkpoint/restore before protected data or source changes. Fresh observations and any continuation still require their actual authority; this topic supplies no retry, service or private-state permission.
